## About The Project

A modern, responsive personal portfolio website built with **React.js** and **Tailwind CSS**.

The portfolio showcases my development journey, technical skills, selected projects, and professional background through a distinctive visual identity and an engaging user experience.

## Key Features

- **Modern Design:** A clean, minimal, and visually distinctive interface.
- **Responsive Layout:** Optimized for mobile, tablet, and desktop screens.
- **Projects Showcase:** A dedicated section highlighting selected projects, technologies, and key details.
- **Technical Skills:** An organized presentation of technical skills, tools, and technologies.
- **Interactive UI:** Smooth transitions, subtle hover effects, and scroll-based reveal animations.
- **Contact Section:** Quick access to professional profiles and contact information.
- **Accessibility:** Semantic HTML structure and accessible interface elements.

## Tech Stack

| Technology | Description |
|---|---|
| React.js | Building reusable UI components |
| Vite | Fast development server and build tool |
| Tailwind CSS | Utility-first CSS framework |
| JavaScript (ES6+) | Application logic and interactivity |
| React Icons | Icon library for React |
| CSS Transitions | Smooth visual transitions and hover effects |
| Intersection Observer API | Scroll-based reveal animations |

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Youssef-W-Bashir/youssef-waleed-portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd my-portifolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application in your browser.

### 5. Build for Production

```bash
npm run build
```
